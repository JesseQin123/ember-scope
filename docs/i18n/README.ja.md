# Ember Scope

**React、TypeScript、Three.js で作られた、オープンソースのインタラクティブな森林火災ビジュアライゼーション。**

[English](../../README.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md) · [Français](README.fr.md) · [日本語](README.ja.md)

架空の山岳地帯で、発火から4日間の推移を探索できます。タイムラインを操作し、ドローンの模擬カメラ映像を確認し、2D・3D を切り替え、航空機の投下を追跡できます。地形、テレメトリー、火災範囲、グラフは同じ決定論的な再生時刻に従います。

> **合成デモ：** 地形、事象、テレメトリー、センサー映像、対応資源の活動はすべて模擬データです。リアルタイム監視、物理的な火災予測、救助指揮、緊急時の判断には使用できません。

**紹介文：** Ember Scope はオープンソースの森林火災ビジュアライゼーションです。架空の山岳地帯で4日間の推移を再生し、6機の模擬ドローンと13の対応資源を確認できます。単一のタイムラインが場面とグラフを同期します。すべてのデータは合成され、再現可能で、ローカルで動作します。

## 主な機能

- **Incident：** 侵食地形、森林、つながった貯水池と河川、不規則な火災境界、焼失域、日付、レイヤー、透明度、連動する3つのグラフ。
- **Drones：** 選択可能な6機、電池・高度・状態、有効な軌跡、最終テレメトリーの固定、同じシーンのカメラ、相対熱度 IR/Thermal、ズーム、追跡。
- **Resources：** 航空機、車両、隊員など13の資源。種類別の手続き型モデル、追跡・コックピット視点、模擬積載量、空中投下、巻き戻せる地表の痕跡。
- **再生：** 一時停止、シーク、再生し直し、速度、キーボード操作、2D/3D、明暗テーマ、軽量表示、WebGL 非対応時の明示的な代替表示。

アプリの UI は英語です。5言語の README はドキュメントの翻訳であり、UI の多言語化ではありません。

## ローカルで起動

Node.js 22.12 以降、npm、WebGL2 対応ブラウザーが必要です。

```sh
git clone https://github.com/JesseQin123/ember-scope.git
cd ember-scope
npm ci
npm run dev
```

**http://127.0.0.1:5173/** を開いてください。API キー、バックエンド、外部地図サービスは不要です。

```sh
npm test
npm run build
npm run preview
```

静的ビルドのプレビューは http://127.0.0.1:4173/ です。ブラウザーテストには Google Chrome が必要です。開発サーバーを起動したまま、別の端末で `npm run test:e2e` を実行します。`npm run verify` はスクリーンショットと性能記録を生成します。別ポートは `EMBER_BASE_URL` で指定できます。

## 操作

ドラッグで回転、右ドラッグで移動、ホイールで拡大縮小します。タイムラインや日付から時刻を変更できます。入力欄以外では Space で再生・停止。タイムラインの矢印キーはアーカイブ時間を16分、Shift 併用では96分進めます。リストやマーカーから対象を選択できます。Reset view はカメラだけを戻します。ページが非表示になると再生は停止します。

## 決定性・テスト・制限

唯一の整数再生座標は 0〜3600 です。1単位はアーカイブの96秒に対応し、架空の Day 01 12:00 から Day 05 12:00 までを表します。1× では実時間1秒が16分、4× では全体が約90秒です。火災は固定の128×128到達時刻グリッドから生成され、水面は燃えません。巻き戻すと同じ状態に戻ります。ドローンは圧縮された記録のスナップショットであり、4日間連続飛行の物理モデルではありません。

初版は23件のシミュレーション・状態テストと14件のブラウザーテストを通過しています。[シナリオ規則](../SCENARIO.md)と[検証記録](../VALIDATION.md)を参照してください。モデルは簡略化され、煙は粒子表現、熱映像は相対値です。投下は火災スクリプトを消火しません。元作品とピクセル単位で同一とは主張しません。
