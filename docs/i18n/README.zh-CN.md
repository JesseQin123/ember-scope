# Ember Scope

**基于 React、TypeScript 和 Three.js 的开源交互式野火可视化。**

[English](../../README.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md) · [Français](README.fr.md) · [日本語](README.ja.md)

从初始起火到四天后的火场档案，探索虚构山地事件。拖动时间轴、查看无人机模拟画面、切换二维与三维地图，并跟随飞机观察脚本投放。场景、遥测和曲线共享同一确定性时间轴。

> **合成演示：** 地形、事件、遥测、传感器画面和资源作业全部为模拟数据。本项目不用于实时监测、火势预测、救援调度或应急决策。

**介绍文案：** Ember Scope 是一个开源交互式野火可视化项目。在虚构的山地中回放四天火势，查看六架模拟无人机，跟随十三个响应资源。所有画面和曲线由同一时间轴驱动，数据可复现，并可在本地运行。

## 功能

- **Incident：** 侵蚀地形、森林、连通河湖、不规则火线、燃烧区域、日期标记、图层与透明度，以及三条联动曲线。
- **Drones：** 六架可选无人机、电量/高度/状态、有效轨迹、最后有效遥测冻结、同场景摄像机、相对热度 IR/Thermal、缩放与跟随。
- **Resources：** 十三架飞机、车辆及人员小组，独立程序化模型、跟随/驾驶舱、脚本载荷、空中投放及可回退地面痕迹。
- **回放：** 播放、暂停、拖动、重播、速度、快捷键、二维/三维、明暗主题、低画质与 WebGL 降级。

## 本地运行

需要 Node.js 22.12+、npm 和支持 WebGL2 的浏览器。

```sh
git clone https://github.com/JesseQin123/ember-scope.git
cd ember-scope
npm ci
npm run dev
```

打开 **http://127.0.0.1:5173/**。无 API 密钥、后端或外部地图依赖。

```sh
npm test
npm run build
npm run preview
```

静态预览地址为 http://127.0.0.1:4173/。浏览器测试需要已安装 Google Chrome；保持开发服务器运行，在另一个终端执行 `npm run test:e2e`。执行 `npm run verify` 可生成截图与性能记录。非默认端口可通过 `EMBER_BASE_URL` 指定。

## 操作

拖动旋转、右键拖动平移、滚轮缩放。底部时间轴与日期标记用于跳转；非输入区按空格播放或暂停。时间轴方向键调整 16 分钟档案时间，Shift 加方向键调整 96 分钟。列表或场景标记均可选择对象；Reset view 只重置相机。页面进入后台会暂停。

## 确定性、测试与限制

唯一整数播放坐标为 0–3600，每单位对应 96 秒档案时间，覆盖虚构 Day 01 12:00 至 Day 05 12:00。1× 时每现实秒推进 16 档案分钟，4× 时约 90 秒播完。火势由固定 128×128 到达时间网格产生，水面不会起火。回退会恢复相同状态。无人机是压缩档案快照，不是连续飞行四天的物理模拟。

初版通过 23 项数据/状态测试和 14 项浏览器测试。[场景规则](../SCENARIO.md)与[验证说明](../VALIDATION.md)提供细节。模型是风格化几何；烟流为粒子；热成像展示相对热度；投放不会改变脚本火势。不宣称与参考作品像素级一致。
